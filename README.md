# Werks releases

Installers for **NestWerks**, **QuoteWerks** and the **Werks** bundle (both in one window), from Weld Werks LLC.

The apps check this page for updates on their own. When a newer version is here, the owner profile sees
**UPDATE READY** and installs it from Settings → Updates. Every installer is checked against `SHA256SUMS.txt`
before it runs. Your quotes, jobs, parts and tools stay where they are.

To install by hand, open the newest release on the right and download the `-Setup-` file for your product.
